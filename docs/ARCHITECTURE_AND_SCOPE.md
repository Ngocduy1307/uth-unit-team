# Kiến trúc, phạm vi và truy xuất yêu cầu

## Ranh giới trách nhiệm
DATA-AI: intake kỹ thuật, manifest/hash, OCR, layout classification suggestion, field extraction suggestion, source anchors, CSV normalization, transaction classification suggestion, payroll-to-credit candidate matching, evidence ledger data, data-quality flags và output contract.

Backend: public API, đăng nhập/SSO, RBAC, tenant isolation, xác minh chủ tài khoản, quyền Maker/Checker, trạng thái hồ sơ nghiệp vụ, điều phối Camunda và gọi các service nội bộ.

Business Logic/Financial Engine: eligible net income cuối cùng theo chính sách, expense floor, debt consolidation/deduplication, lịch trả nợ P, residual R, DSR Q, stress scenarios và policy labels. DATA-AI không tự tính hoặc quyết định các nội dung này.

Camunda: chỉ nhận opaque IDs và routing status, không nhận tên, số tài khoản, sao kê hoặc số tiền.

## SRS constraints encoded in this baseline
- Formats: PDF, JPG, JPEG, PNG, UTF-8 CSV.
- Limits: 10 files/case, 20 MiB/file, 60 PDF pages, 3,000 CSV data rows.
- SHA-256 duplicate detection is scoped to a case. Hash is integrity evidence only, not document authenticity.
- Raw OCR tokens retain page number and pixel bounding box. Low confidence requires Maker review.
- Credit transaction categories are suggestions only. `is_income_eligible` remains false.
- Missing evidence is not imputed. No averaging to fill missing months.
- Original filename is metadata only; storage path is generated by the service.

## Not represented as completed
- Official 6 approved document layouts and exact 20 critical fields are pending PO/bank sign-off.
- The 2 official bank statement CSV schemas are pending. Generic header aliases in the starter are only a local demo adapter, not an approved bank mapping.
- Malware scanning and process sandboxing are not implemented by this baseline. It must not be used with real customer evidence until these controls exist and are tested.
- File storage is local disk and not WORM/immutable object storage. Production requires approved object storage, encryption, retention/deletion and backup controls.
- No tenant isolation is enforced inside this service. It must run on a private network behind Spring Boot and must be extended with bank/tenant-scoped DB policies before multi-bank pilot.
- OCR quality metrics, 6-layout Macro F1, extraction coverage and payroll match precision/coverage require a labeled independent dataset. They are not claimed by this code.
